1. Add Clinical Record

Saving a record stores it in the database and writes its SHA-256 hash to the Ethereum Sepolia blockchain.

2. Verify Records & 3. Demonstrate Tampering

Tamper edits the glucose value directly in the database (like an attacker who bypasses the blockchain). The dashboard re-hashes the data, compares it with the hash on the blockchain, and flags the record as TAMPERED. Restore puts the original value back.
